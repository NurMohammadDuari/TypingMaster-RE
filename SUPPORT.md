# Support

## Getting help

This is a **public research repository** containing a reverse-engineering study.
Support is best-effort, from the maintainer and the community.

| I want to… | Do this |
|---|---|
| Understand what this is | Read `README.md` |
| Understand the analysis | Read `analysis/ANALYSIS-DEEP.md` |
| Understand the legal position | Read `LICENSE` and `NOTICE.md` |
| **Contribute** | Read `CONTRIBUTING.md`, then `docs/COMMUNITY.md` |
| Ask a question or share results | Open a [Discussion](https://github.com/NurMohammadDuari/TypingMaster-RE/discussions) |
| Report a bug in this repository | Open an issue using the *Bug report* template |
| Correct the analysis | Open an issue using the *Analysis correction* template |
| Report a security problem | **Privately** — see `SECURITY.md` |

> This repository is the **analysis only**. It does not contain the studied
> program, its runtime, or its decompilation — those cannot be redistributed
> and live in a private companion repository. See `NOTICE.md`.

## Before opening an issue

1. Search existing issues and discussions first.
2. Name the file and section you were reading (e.g.
   `analysis/ANALYSIS-DEEP.md` §6).
3. If your question is about *running* the program rather than the analysis,
   note that the program is not distributed here.

## Not supported

- **Licence bypass.** No keys, cracks or activation help — see `CONTRIBUTING.md`.
- **Upstream bugs.** Problems inside the studied program, Wine, or the
  Freedesktop runtime belong to those projects, not here.
- **Redistribution requests.** This repository ships no proprietary files, so
  it cannot provide them.

## Response expectations

This is a volunteer project. There is no SLA and no guaranteed response time.
Reports are reviewed on a best-effort basis.
